1. Register an endpoint: 
    POST /v2/webhooks
{ "url": "https://example.com/hooks/brightline", "events": ["alert.opened", "alert.closed", "site.pto"] }
  2. Store the returned signing_secret.
  3. Verify each delivery by computing HMAC-SHA256 of the raw body with the secret and comparing to the X-Brightline-Signature header.
  4. Respond with 2xx within 5 seconds. Failed deliveries retry with exponential backoff for 24 hours.

Payload example:

{
  "event": "alert.opened",
  "site_id": "st_48a1",
  "severity": "red",
  "occurred_at": "2026-06-12T14:03:00Z"
}
