The new fields are available on March 3, 2026 for all partners with a valid OAuth2 token and the reports:read scope. No scope changes or contract amendments are required to access them.

New Response Fields

FieldTypeDescription
weather_adjustment_factorfloatDecimal multiplier (e.g., 0.92 = −8% weather impact) for the period.
weather_adjusted_estimate_kwhfloatOriginal estimate revised by the weather adjustment factor.
weather_event_flagsarray of stringsList of internal event codes (e.g., WEF-STORM-024) affecting the period.

Request Example

Add the query parameter include_weather_adjustments=true to your existing GET /v2/reports/production request. Omitting the parameter returns the previous response shape with no new fields, preserving backward compatibility.

Retroactive Data

Weather adjustment data is available retroactively for periods back to January 1, 2024. Requests for periods before that date will return null for all three fields.

For details on retrieving production estimates through the API, see Retrieve Production Estimates via the Partner API.
