Overview

The Partner API exposes a /v2/reports/schedules resource that lets you create, update, list, and delete recurring report delivery jobs for one or more sites under your OAuth2 credentials.

Creating a Report Schedule

Send a POST request to /v2/reports/schedules with a JSON body. Required fields are shown in the table below:

FieldTypeRequiredDescription
site_idstringYesBrightline site identifier
frequencystringYesdaily, weekly, or monthly
delivery_methodstringYeswebhook or pull
webhook_urlstringIf webhookMust match a registered endpoint
include_weather_adjustedbooleanNoDefaults to false
start_dateISO 8601 dateNoDefaults to next occurrence

Response & IDs

A successful 201 Created response returns a schedule_id (e.g., rsch_8a3f2c) you should store for future updates or deletions. If the webhook_url is not yet registered, the API returns error code ERR_WEBHOOK_URL_UNREGISTERED (422).

Idempotency

Include an Idempotency-Key header on POST requests to prevent duplicate schedules if a request is retried. See What Is an Idempotency Key and Why Do I Need One? for details.

Weather-Adjusted Fields

When include_weather_adjusted is true, each delivered report includes the fields described in Weather Adjustment Fields Now Available — Partner API Reports Endpoint.

Rate Limits

You may create up to 50 active schedules per OAuth2 client. Exceeding this limit returns ERR_SCHEDULE_LIMIT_EXCEEDED (429).
