What Is Changing

The updated policy takes effect for all webhook subscriptions on April 1, 2026. Partners do not need to rotate credentials or re-register endpoints; the new schedule applies automatically.

New Retry Schedule

Failure Codes

Events that exhaust all seven attempts will be marked WEBHOOK_DELIVERY_FAILED (error code WH-4071) in the Partner Dashboard under Developer → Webhook Logs. Missed events can still be recovered using the backfill endpoint; see how to handle pagination in Partner API webhook backfill requests for details.

Action Required

  • Ensure your endpoint returns HTTP 2xx within 10 seconds; responses slower than 10 s are treated as failures.
  • Update any monitoring alerts that rely on the previous 24-hour discard window.
