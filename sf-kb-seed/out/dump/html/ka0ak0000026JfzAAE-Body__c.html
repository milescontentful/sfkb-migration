What Changed

Effective June 10, 2026, the Partner API exposes three new operations for site ownership transfer:

  • POST /v2/sites/{site_id}/ownership-transfer — initiates a transfer request
  • GET /v2/sites/{site_id}/ownership-transfer/{transfer_id} — polls current status
  • DELETE /v2/sites/{site_id}/ownership-transfer/{transfer_id} — cancels a pending transfer

Status Lifecycle

StatusMeaning
PENDING_DOCSAwaiting required homeowner documents
UNDER_REVIEWBrightline compliance team reviewing submission
APPROVEDTransfer complete; new owner credentials issued
REJECTEDTransfer denied; rejection_reason field populated

Key Details

  • Transfer requests must include an Idempotency-Key header. See What is an idempotency key and why do I need one? for guidance.
  • Brightline targets a 3-business-day review window for complete submissions.
  • A site.ownership_transfer.status_changed webhook event fires on every status transition.
  • A $25 processing fee per transfer is billed to the partner account monthly.

Full schema documentation is available in the Partner API reference portal under Sites > Ownership Transfer.
