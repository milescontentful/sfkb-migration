Before you begin: You must be the account owner with full Alert Management permissions. Suppression rules are available on Brightline Home app version 4.5.0 or later. Rules apply only to the site associated with your account; households with multiple sites must configure rules per site. Note that suppression rules cannot be applied to any alert with a Critical (ALT-5xx) or Safety (ALT-6xx) code.

  1. Open Brightline Home and tap Settings (gear icon, top-right corner), then select Alerts & Notifications.
  2. Tap Suppression Rules, then tap Add New Rule.
  3. In the Alert Type field, search for or browse to the alert code you want to suppress — for example, ALT-204: Low Production Warning. Only alert codes that have been triggered at least once on your system appear in this list.
  4. Under Trigger Condition, define when the rule applies. Choose one or more conditions:
    • Time window — suppress the alert only between specified hours (for example, 07:00–09:00 to ignore early-morning shading alerts).
    • Duration threshold — suppress only if the alert clears automatically within a set number of minutes (2–30 minutes).
    • Repeat frequency — suppress if the same code fires more than a specified number of times within a rolling 7-day window.
  5. Set the Rule Expiry date. Rules must have an end date; the maximum is 180 days. You can renew a rule before it expires.
  6. Tap Save Rule. A confirmation banner appears: Suppression rule activated. Matching alerts will be logged silently under Alert History.
  7. To review suppressed alerts at any time, go to Alerts > Alert History and toggle the Show Suppressed filter to On.

Troubleshooting

The alert code I want to suppress is not listed. Suppression rules can only be created for alert codes your system has previously generated. If you are trying to prevent a future alert type, contact Brightline Support to discuss whether a system-wide sensitivity adjustment is appropriate for your installation.

Suppressed alerts are still sending push notifications. Suppression rules silence in-app alert cards but do not automatically disable push notifications configured under Settings > Notifications > Push Preferences. Disable the corresponding notification toggle there to stop push alerts for the suppressed code.

My rule expired and I need to renew it. Go to Settings > Alerts & Notifications > Suppression Rules, find the expired rule (marked with a gray Expired badge), and tap Renew to extend it by up to 180 additional days. If your system's production readings are frequently triggering low-production alerts, review Why Does My Production Estimate Differ from My Actual Output to determine whether an underlying production issue — rather than a false alarm — may be causing the alerts.
