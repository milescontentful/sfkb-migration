Endpoint Details

Released February 3, 2026, the new endpoint is:

GET /v1/sites/{site_id}/neighbor-comparison

Required OAuth2 Scope

reports:read — no additional scope approval is needed if your application already holds this permission.

Query Parameters

ParameterTypeRequiredDescription
periodstringYes"monthly" or "annual"
yearintegerYes4-digit year, e.g. 2025
monthintegerNo1–12; required if period=monthly

Response Fields

  • peer_median_kwh — median output of the matched peer group
  • peer_p25_kwh — 25th percentile
  • peer_p75_kwh — 75th percentile
  • site_output_kwh — the enrolled site's actual output
  • peer_count — number of anonymized households in the comparison

Error Codes

If fewer than 8 peer households match the site, the API returns HTTP 422 with error code NEIGHBOR_PEER_POOL_TOO_SMALL. For general 4xx guidance, see Partner API 4xx Error Code Reference.

Rate limits follow standard Partner API policy: 120 requests per minute per client credential.
