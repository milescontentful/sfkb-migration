Prerequisites: You must have a valid OAuth2 access token with at least the read:sites scope. Pagination applies to any Partner API collection endpoint that returns a pagination object in its response envelope, including /v2/sites, /v2/reports, and /v2/alerts. Confirm your client library is up to date; see Partner API SDK Launch – Python & Node for version requirements.

  1. Make your initial request to the desired collection endpoint. Include the query parameter page_size (integer, 1–500; default 100) to control how many records are returned per page. Example: GET /v2/sites?page_size=200.
  2. Inspect the response envelope's pagination object. It contains three fields: total_records (total matching items), next_cursor (an opaque Base64 string), and has_more (boolean).
  3. If has_more is true, append the cursor query parameter to your next request using the value from next_cursor. Example: GET /v2/sites?page_size=200&cursor=eyJpZCI6MTIzfQ==.
  4. Repeat step 3, always using the next_cursor from the most recent response, until has_more returns false. Do not store or construct cursors manually; they expire after 15 minutes of inactivity.
  5. Aggregate your results across all pages in your application layer. Do not rely on record order across separate cursor sessions, as new records may be inserted between requests.

Troubleshooting

Error CURSOR_EXPIRED (HTTP 400): Your cursor was unused for more than 15 minutes or was malformed. Restart pagination from the first request with no cursor parameter.

Error INVALID_PAGE_SIZE (HTTP 422): Your page_size value is outside the 1–500 range. Adjust the parameter and retry.

Duplicate records across pages: This can occur if you reuse an old cursor after your access token was refreshed. Always pair a new token with a fresh pagination session.

Unexpectedly low total_records: Collection endpoints respect your OAuth2 scope's site permissions. If you expect more records, verify your token's granted scopes in the Developer Portal under Apps > Your App > Scopes. For report-specific pagination details, see How to Configure Report Schedules via the Partner API.
