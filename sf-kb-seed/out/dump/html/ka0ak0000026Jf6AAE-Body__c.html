Available Now

The Webhook Retry Visibility Dashboard went live on March 18, 2026 and is accessible to all active Partner API accounts at Developer → Webhook Logs in the Partner Portal.

Key Features

  • Per-event attempt timeline: See each retry attempt, its timestamp, HTTP status code, and round-trip latency in milliseconds.
  • Failure reason codes: Codes such as WH-4001 (connection refused), WH-4022 (TLS handshake failure), and WH-5003 (endpoint timeout) are now surfaced inline.
  • Manual re-delivery: Any event with status PENDING_RETRY or WEBHOOK_DELIVERY_FAILED can be manually re-queued using the Resend button; re-queued events respect the current retry schedule.
  • Filterable log export: Export up to 90 days of webhook logs as CSV or JSON from the Export Logs menu.

Retention Policy

For accounts using the Python or Node SDKs, helper methods for programmatic log retrieval are documented in the SDK changelog; see Partner API SDK v2 breaking changes (March 2026) for version compatibility notes.
