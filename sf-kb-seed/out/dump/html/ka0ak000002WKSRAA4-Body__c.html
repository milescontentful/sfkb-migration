Endpoint Details

The new endpoint is available in API v2 only and requires the sites:stats:read OAuth2 scope.

GET /v2/sites/{site_id}/stats/lifetime

Response Fields

FieldTypeDescription
total_generation_kwhnumberCumulative AC output since activation
estimated_savings_usdnumberDollar savings at blended rate on record
co2_offset_metric_tonsnumberCO₂ avoided using EPA eGrid regional factor
data_through_dateISO 8601 dateMost recent date included in totals

Rate Limits & Caching

The endpoint is rate-limited to 120 requests per minute per OAuth client. Lifetime totals are recalculated nightly; polling more frequently than once every 24 hours is unnecessary and will count against your quota.

Error Handling

A 404 Site Not Found response indicates the site_id is not authorized under your OAuth token. For guidance on handling unexpected 4xx responses, see Interpret 4xx Error Codes in the Partner API. This endpoint went live on August 11, 2025 and is not back-ported to API v1.
