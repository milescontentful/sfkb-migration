Alongside the consumer-facing Neighbor Comparison feature in Brightline Home, Brightline's Partner API now exposes the same benchmarking dataset through a dedicated REST endpoint. Available to all OAuth2-authenticated partners with the reports:read scope, the endpoint returns aggregated median, 25th-percentile, and 75th-percentile production figures for the anonymized peer group matched to a given site, enabling partners to surface actionable benchmarking insights inside their own dashboards and customer-facing tools.
