Prerequisite: a Partner API application with a client ID and secret from the Partner Portal.

Request

POST https://api.brightlinesolar.com/oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&client_id=YOUR_ID&client_secret=YOUR_SECRET&scope=sites:read production:read

Response

{
  "access_token": "eyJ...",
  "token_type": "Bearer",
  "expires_in": 3600
}

Cache the token and refresh it before expiry. Tokens are not revoked on rotation of the secret for 10 minutes, giving you a rollover window.
