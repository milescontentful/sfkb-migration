Effective Date: July 1, 2026

The following rate limits will apply to all sandbox credentials from July 1 onward:

Quota TypePrevious Sandbox LimitNew Sandbox Limit (matches production)
Requests per minute (per client)Unlimited120 rpm
Requests per day (per client)Unlimited50,000 req/day
Webhook delivery attempts (sandbox replay)Unlimited500 replays/day
OAuth2 token requests per hourUnlimited60 req/hour

What Partners Should Do Before July 1

  • Review integration code for loops or bulk-fetch patterns that rely on the sandbox being unrestricted.
  • Implement Retry-After header handling; the sandbox will return HTTP 429 with error code RATE_LIMIT_EXCEEDED identically to production.
  • Test pagination logic against large synthetic datasets — see how to paginate through large result sets in the Partner API.

Sandbox-Specific Exceptions

The sandbox will continue to accept OAuth2 token requests using the static test credential pair (sandbox_client_id / sandbox_client_secret) without requiring a registered redirect URI. All other behaviors, including error codes and response shapes, will be identical to production.
